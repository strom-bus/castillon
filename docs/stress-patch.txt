Load test for the audio engine.

24 oscillators over five cascade levels, covering all ten waveforms, all four filter types and
all four sequence lengths, at 300 BPM on loop. Paste the code below into the PATCH CODE field.

What to listen and look for:
  - crackling or dropouts, which would mean the scheduler is missing its window
  - the output clipping rather than being held by the limiter
  - the voice counter in the transport: past 48 of 64, nodes stop layering and restart instead,
    and the meter goes bright. That is the designed degradation, not a fault.

The code is checked on every test run (see src/state/stressPatch.test.ts), so a change to the
patch-code format cannot rot it silently — CI fails instead.
